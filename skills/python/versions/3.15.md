# Python 3.15+

Apply these rules when the project's lowest supported Python version is 3.15 or newer.

- Don't put an import inside a function or method body to defer its cost. If the code that uses the import may not run, write `lazy import <mod>` or `lazy from <mod> import <name>` at module level instead (PEP 810).
- `lazy` works only at module level. It's not allowed inside functions, class bodies, `try`/`except`, or `with` blocks.
- `lazy` doesn't get used at runtime under `if TYPE_CHECKING:`, so you might as well skip using it there.
- Keep a plain top-level import when the module is always used, for example on import or in every code path.
